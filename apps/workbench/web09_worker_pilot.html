Python in a Web Worker

This WEB-09 proof of concept fetches one locally staged, SHA-256-verified candidate wheel, then executes the actual EnergyData Kit Python engine in a dedicated browser worker. It is not a public product or approved package distribution.

Data: four hard-coded synthetic 15-minute scenarios, including gaps, duplicates and daylight-saving transitions. No customer CSV input is available. The staged candidate manifest is review-only and does not authenticate the publisher.

Python and its dependencies still download from third-party hosts on first run. Execution happens only after you click Run.

Not started. No external runtime loaded.

No report.

To test, stage a locally built wheel plus candidate manifest under candidate-assets/, then serve the directory over localhost HTTP. Do not deploy the staged assets, use operational data, or treat report parity as independently validated on this path until an actual browser smoke test passes.
